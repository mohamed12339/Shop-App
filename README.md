## 🚀 Features
❤ Add to cart for quick purchases  
🔥 Explore products with real-time search and debounce effect  
⚡ Manage favorites for personalized shopping  
📦 Clean Architecture + Repository Pattern  
🎯 Advanced State Management using Bloc & Cubit  
🌐 API Integration using Dio for Route E-Commerce API (https://ecommerce.routemisr.com/)  
📶 Handles internet issues gracefully with Dio exceptions  
🧪 Full error handling for server & client-side issues  
🔁 Async API calls using Future.wait for optimized loading  
📱 Responsive design with smooth neon UI  
🎨 A mobile application that allows users to browse products, search, add to cart, manage favorites, and update their profile, integrated with REST APIs for authentication, categories, and products  

Additional modules:  
- Auth for user authentication  
- Home for browsing and discovery  
- Product Details for in-depth info  
- Network layer handling all API interactions  

## 🧰 Prerequisites
- Flutter SDK installed  
- Route E-Commerce API: Access at https://ecommerce.routemisr.com (no Firebase required)  

## 🛠 Getting Started
To run the app locally:

```bash
git clone https://github.com/mohamed12339/Shop-App
cd Shop-App
flutter pub get
```

For iOS:
```bash
cd ios
pod install
```

That’s it!  
Feel free to run this code, edit it, and use any part of it in your own projects.  
And don’t forget to ⭐ star the repo if you liked it!
